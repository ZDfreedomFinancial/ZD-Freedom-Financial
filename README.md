## Free hosting
This is a static website, so it can be hosted at no cost on a static hosting service. One straightforward option is GitHub Pages.

Basic GitHub Pages workflow:
1. Create a GitHub account if you do not already have one.
2. Create a new repository for the website.
3. Upload everything inside this folder, keeping the `assets` folder intact.
4. In the repository settings, enable Pages and publish from the main branch/root.
5. Your site will receive a public `github.io` address.
